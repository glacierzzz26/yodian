## 与设计契约的对齐点

- **桌台派生状态**（3.5）：Tbmgr.vue 明确「当前状态」为派生字段不落库，仅维护区域/座位/结账模式；与阶段 1.2 TableMap 同口径。
- **六口径对账**（5）：Recon.vue 六口径汇总 + 差异项标红 + 处理建议（现金短款需班次清点确认，不计入跑单）；`diffCount`/`totalDiff` 驱动页头告警，全平显示成功态。
- **权限矩阵**（16.2）：Staff.vue 三角色管理，店长须至少 1 人、不可停用本人；路由守卫 + 菜单可见性沿用阶段 1.1 双控，退款/核销/对账/降级仅 owner。
- **按人收费**（11 章）：Perhead.vue 与会话人数联动（结账时以就餐人数为准）；儿童半价与最低起收配置即时生效。
- **凭据处理**（12.6）：Setting.vue 只读展示掩码商户号（`wx********8888` / `19******001`），不保存密钥；配置入口提示「部署环境 .env 写入」。备份文档同步标注「凭据备份与数据库备份分开存放」。
- **二维码生命周期**（4.4）：Qrcode.vue 桌贴有效期默认 365 天，过期后扫码提示联系服务员（降级模式入口），与设计「一桌一码」一致。
- **数据诚实**：Import.vue 仅做预检与预览（mock），不上传不落库；Recon.vue 只有 1 个真实差异行（现金短款 ¥4.85），差异行明确标注演示数据来源。

## 本阶段修复

1. **Recon.vue 模板解析错误（TS1005）**：line 91 三元表达式后误多一个 `{`（`'' }{{ ... }}`）触发 Vue 模板 parser 崩溃。改为 `diffText()` helper 函数统一输出 `+/-` 符号与两位小数。
2. **Menu.vue `editing` 未使用**：新增/编辑状态由 `isNew` 承担，`editing` ref 冗余 → 删除。
3. **Perhead.vue `computed` 未使用**：移除 import。
4. **Tbmgr.vue 可空性收窄失败**：`editing.table` 内部类型误带 `| null`（实际从未赋 null）→ 收紧为 `TableInfo`；session 列三次重复 `(record as FlatRow).table.session` 无法跨模板分支收窄 → 提取 `sessionText()` helper。
