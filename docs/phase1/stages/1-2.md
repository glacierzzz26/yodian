## 与设计契约的对齐点

- **三态结账**（3.7）：Pos.vue 内先付/后付/仅点单同屏切换，随所选桌台模式自动生效；后付挂账单收款方式在结账时选择（补录阶段不收款）。
- **状态枚举**（7.1）：订单六态 `pending/paid/preparing/served/unsettled/manual` 统一映射中文展示，颜色语义：待支付-蓝 / 制作中-橙 / 已出餐-绿 / 未结账-红 / 需人工-金。
- **桌台派生状态**（3.5）：`status` 为派生字段；未结账（`unsettled>0`）、待清台（`waitClean`）、并桌（`merged`）、结账锁单（`lockedForBill`）均为展示层派生，不落库。
- **权限矩阵**（16.2）：路由守卫 + 菜单可见性双控；`manual` 处理动作、退款、降级、对账仅 owner 可见可操作；cashier 只读查看需人工队列。
- **KDS 15s 自动拉新 + 1s 计时**：对应设计「后厨大屏常驻」；超时（>15min）红框高亮；档口 tab 来自订单 station 字段。
- **错误码/信封**：所有页面通过 mock 模拟 `{code,msg,data}` 语义，异常统一 `message.error`，不做假成功。

## 基础设施修正（脚手架阶段遗留，本阶段发现并修复）

1. **`@` 别名 TS 不识别**：vite.config 有 alias，tsconfig.app.json 缺 `paths` → 全部 `@/` 导入报 `TS2307`。补 `"paths": {"@/*": ["./src/*"]}`（TS6 弃用 baseUrl，paths 直接相对 tsconfig 解析）。
2. **路由→视图显式映射**：原按 `capitalize(key)` 推导文件名，与「tables/orders/print」等 key 不一致。改为 `VIEW_MAP` 显式映射，页面命名可自由描述（`TableMap/OrderList/PrintTasks`），后续阶段加页不踩坑。
3. **脚手架残留清理**：删除 `HelloWorld.vue`、`style.css`、`hero.png/vite.svg/vue.svg`（仅被 HelloWorld 引用）。
4. **TableMap 样式去重**：scoped 与 `global.css`「桌台图」段重复，删除 scoped，统一由全局令牌持有。
5. **Dashboard 未用 ref、mock 未用参数、Pos 选桌弹窗 `<a-space>` 作用域错误** 等 `noUnusedLocals`/类型错误，逐一修复。
