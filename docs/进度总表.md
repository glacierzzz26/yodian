## 关键决策记录

- 商家端/管理后台：**同一 Vue3 Web 工程，路由分区**（设计文档 10.1）；不做小程序。
- KDS 大屏用 antdv `darkAlgorithm` 暗色主题（10.2）。
- 登录：工号 + 密码，三角色（收银员/后厨/店长），权限矩阵见 16.2。
- 前端数据层：先按 16 章接口契约信封（`{code,msg,data}`）搭 mock 适配层，后端就绪后无缝切换真实 API。
- 部署选型：2C2G 低配（15.8），等后端阶段落。
