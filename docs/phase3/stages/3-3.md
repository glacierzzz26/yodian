## 收敛层四文件（工程约束 #1，9.2/9.3 硬约束）

| 文件 | 职责 | 平台分支 |
|---|---|---|
| `utils/auth.ts` | `platform()` + `getLoginCode()` + `silentLogin()`（→ `POST /auth/login`，`channel`=wechat/alipay）+ `relogin()`（401 重登，登成即写 token） | 微信 `uni.login({provider:'weixin'})`；支付宝 `my.getAuthCode({scopes:'auth_base'})`；**不索取昵称头像**（9.4） |
| `utils/entry.ts` | `parseEntry(options)`：微信解 `options.scene`（URL 编码的 `tid=&sig=`，本地 `parseQuery`，兜底 `options.tid/sig`）；支付宝 `query` 对象/options | 微信/支付宝两套取值逻辑 |
| `utils/pay.ts` | `requestPayment`（微信 `uni.requestPayment` / 支付宝 `my.tradePay`） | 3.4 使用，本期已就位 |
| `utils/notify.ts` | MVP 占位 `Promise.resolve(false)`（9.3 决策：不做通知，订单轮询替代） | 3.5 使用 |

## 关键实现决策

- **静默登录为入口页启动必经步**：有 token 直接复用，无 token 取平台 code 换 token；401 由 request 层静默重登（工程约束 #3/#4），业务流程不被打断。
- **auth↔request 循环依赖靠注入切断**：request.ts 不 import auth，暴露 `setReloginHandler(fn)`；auth.ts 模块加载期注册 `relogin`。编译无循环 chunk 警告。
- **QR 入口映射**：微信 `scene` / 支付宝 `query` 均归一为 `{tid, sig}`（5.4 差异，`?tid=&sig=` 无 ts）；**本地不验签**，真校验 = 入口页调 `/tables/:tid/menu`（后端验 sig，失败 → 无效屏），H5 语义在 mini-program 内承接。
- **BFF 只读、下单禁离线**：菜单可缓存浏览但下单入口禁用（弱网，9.8 语义在 3.4 落实）。
- **pinia 版本钉在 2.x**：官方模板 TS ^4.9.4，pinia@4 要求 TS≥5.6 冲突 → `pinia@^2.3.1`（稳定且满足 uni-app）。
- **sass 为模板缺失项**：`npm install -D sass` 补齐（Vite CSS 预处理器）。
- **主题变量内联 uni.scss（偏差，见下）**：uni-app 会把 uni.scss 注入每个页面组件，uni.scss 内 `@import "./styles/theme.scss"` 的相对路径会相对页面目录解析而失败 → 变量直接内联在 uni.scss，删除 `src/styles/`。

## 验收证据（WSL 可验证部分）

```
npm run build:mp-weixin  → DONE Build complete → dist/build/mp-weixin
npm run build:mp-alipay  → DONE Build complete → dist/build/mp-alipay
条件编译收敛检查（读编译产物）：
  mp-weixin/utils/auth.js   → uni.login({provider:"weixin"}) + channel "wechat"，无 my.getAuthCode
  mp-alipay/utils/auth.js   → my.getAuthCode({scopes:"auth_base"}) + channel "alipay"，无 uni.login
  mp-weixin/utils/entry.js  → 解 scene(query) 分支；mp-alipay/utils/entry.js → query 对象分支
  mp-weixin/pages/entry/index → parseEntry + redirectTo + 无效屏标记，wxml 含「二维码无效」，app.json pages=[entry,menu]
easycom 注册：
  mp-weixin/index.json 与 mp-alipay/index.json 均 usingComponents 注册 wd-button（指向 wot-design-uni 组件）
登录后端链（3.1 已验）：POST /auth/login 取码换 token → GET /tables/:tid/menu 验 sig → 数据即本页 fetchMenu 的数据源
```

**未验证项（留待宿主人工）**：真机/模拟器实际扫码静默登录。微信/支付宝开发者工具在 Windows 宿主（设计 §4.9），WSL 内以「双端编译通过 + 编译产物条件收敛正确 + 后端端点（3.1 冒烟 52/52）就绪」作为可验证证据，模拟器实扫属上线前手工检查（与 3.4/3.5 一同过）。
