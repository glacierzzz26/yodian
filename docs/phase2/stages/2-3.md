# 阶段 2.3 · 会话与三态结账

> 归档日期：2026-08-24 ｜ 阶段：✅ 完成
> 续接依据：本归档 + `进度总表.md` + `phase2/design/README.md`；不靠对话记忆。

## 交付物

`server/` 会话生命周期与三态结账闭环：后付/前台结订单即出单（unsettled）→ 结账聚合生成唯一 bill → 支付批量置位 → 清台终态；另含店长核销、部分/全额退款、员工登录。

| 项 | 内容 |
|---|---|
| 员工鉴权 | `service/staff.go` `Authenticate`（bcrypt 校验、停用拦截、登录时间落库）+ `handler/staff.go` `POST /auth/staff/login` → SignStaff（access 2h） |
| 结账 | `service/bill.go` `CreateBill`：服务端聚合会话 unsettled 子单 + postpay/frontend **首次结账**按人项一次性计入（3.8）→ `bills` pending + 生成支付单号 |
| 防并发 | 双防线：① 事务内 `locked_for_bill false→true` 原子条件更新（抢锁失败 → 20004 结账中）；② `uniq_session_active_bill` 部分唯一索引兜底（冲突 → 20010） |
| 账单入账 | `HandleBillPaidLocked`：金额校验（不符置 manual + 30006）→ 事务内 bill→paid + 会话 unsettled 子单**批量**置 paid 挂 bill_id + 插支付记录 → 解锁会话 |
| 清台/核销 | `CloseSession(mode)`：`close` 强制校验未结账/待支付账单（20011 拒绝）；`write_off` 店长强制关台（不受锁单/未结账约束）→ unsettled→written_off、pending 账单→written_off、paid 子单→done、paid 账单→closed、会话 closed、桌台 empty（同事务） |
| 权限 | `middleware.RequireRole`：核销挂 `owner` 白名单，非 owner 403 |
| 退款 | `service/refund.go` `RefundOrder`：prepay paid/preparing/served/partially_refunded 可退；可退额 = paid_amount − 已退；全退→refunded / 部分→partially_refunded；调网关 Refund（mock）+ `refunds` 记录 |
| 账单多单 | 新 bill 创建时先把本会话已支付旧账单 paid→closed，释放 `uniq_session_active_bill`，支持同会话追加账单 |

## 验收证据（curl 全链路 + psql 核验）

1. **员工登录**：1002/123456 → 收银员 token；错误密码 → 40004「工号或密码错误」。
2. **后付全链路**（B01）：下单 → `unsettled`，total=92.00（**后付不含按人项**）；结账 → bill=104.00（92 + 餐位费5×2 + 湿巾1×2）；mock 回调支付 → bill `paid`、订单批量 `paid` 挂 bill_id、payment 1 条 success；**重复回调幂等**；清台 → 订单 `done`、账单 `closed`、会话 `closed`、桌台 `empty`。
3. **未结账清台被拒**：下单不付直接清台 → 20011「存在未结账订单或待支付账单，禁止清台」。
4. **并发结账仅一张 bill**：同会话两个并发 `POST /sessions/:id/bill` → 一个成功、一个 20004「会话结账中」；库中 bill 恰 1 张。
5. **核销权限**：收银员核销 → 40003；店长核销 → 成功（会话 closed、unsettled 订单 → `written_off`、pending 账单 → `written_off`、桌台 empty），且**不受锁单约束**。
6. **退款分流**：prepay 订单支付后部分退 100 分 → `partially_refunded`；再全额退 → `refunded`；再退 → 20014「订单状态不可退款」。

## 关键实现决策

- **支付锁单一持有点**：Redis `pay:lock:<out_trade_no>` 只在顶层 `OrderService.HandlePaidSuccess` 获取一次，账单入账委托 `HandleBillPaidLocked` **不再加锁**（早期双加锁导致自锁死、回调空转的 bug，已修）。
- **按人项折叠进账单总额**：bills 表无明细行，per-head 折入 `total/payable_amount`；明细可追溯性留待 2.4 对账细化。
- **顾客结账绑定**：`POST /sessions/:id/bill` 仅要求顾客 JWT，未严格绑定「下单顾客=结账顾客」（会话按桌台，不追踪桌内具体顾客）；前台收银代结在 2.4 补。
- **账单级退款**：2.3 只做订单级退款；账单级部分退款随 2.4 六口径对账落地。
